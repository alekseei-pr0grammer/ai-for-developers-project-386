# The Handle is permanent and is not a login

A Host's Handle is derived from their Public name at sign-up and never changes afterwards, even when the Public name does. Hosts log in with their email, not the Handle. Handles appear in public booking links that Guests bookmark and Hosts paste into emails and websites, so changing a Handle would silently break every link already shared.

## Considered Options

- **Handle follows the Public name, with redirects from old Handles**: rejected. Old Handles would have to stay reserved forever, and a Handle freed by one Host could be taken by another, sending that Host's Guests to a stranger.
- **Handle doubles as the login username**: rejected. It would make an identifier that is shown to everyone a login credential, and Hosts would need to remember one more thing when email already works.
